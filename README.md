# 3D GROUP — вёрстка

Посмотреть: https://ivanweb1.github.io/3d-group/cases.html (публикуется автоматически при пуше в `main`, закрыто от индексации).

Страницы:
- `cases.html` — «Кейсы» (по прототипу из Figma, `design-v1` в Releases)
- `index.html` — заглушка главной

Картинки, которые нужно сгенерировать: [docs/image-prompts.md](docs/image-prompts.md).

## Стек

- **Vite** — сборка и dev-сервер
- **SCSS + BEM** (`block__element`)
- **GSAP + ScrollTrigger** — анимации при скролле
- **Lenis** — плавный скролл
- **Fancybox** — модальные окна
- **IMask** — маска телефона
- Шрифты: **SuisseIntl** для заголовков (пока подменяется Inter) и **Montserrat** для текста

## Запуск

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # готовые файлы в dist/
```

## Структура

```
index.html
src/
  js/
    main.js
    modules/       smooth-scroll, animations (появление, параллакс кубов), header, cases (фильтр), forms
  assets/images/   cases/ — иконки кейсов, кубы, фон
  scss/
    _variables.scss   цвета, шрифт, брейкпоинты
    _base.scss
    _mixins.scss
    blocks/           header, hero, tasks, catalog, case-card, feedback, footer
    main.scss
```

Атрибуты для анимаций:
- `data-reveal` — элемент плавно появляется при скролле
- `data-fancybox` — открыть модалку
- `data-mask` — маска телефона
- `data-parallax="0.2"` — элемент плывёт при скролле с указанной скоростью

## Фильтр кейсов

Каждой карточке `.case-card` нужны атрибуты:
- `data-sphere` — сфера: `ecommerce`, `corporate`, `industry`, `3d`, `creative`, `production`, `finance`, `realty`, `it`
- `data-format` — формат: `implementation`, `integration`, `development`, `support`
- `data-tags` — платформы через пробел: `bitrix24`, `amocrm`, `sites`
- `data-tasks` — задачи через пробел: `crm-new`, `migration`, `1c`, `sales`, `processes`, `telephony`, `site-crm`, `analytics`, `growth`

Клик по плитке задачи прокручивает к каталогу и оставляет кейсы с этой задачей. Счётчик «N кейсов» на плитке считается сам; если кейсов нет, плитка неактивна и подписана «Скоро».

Поиск ищет по всему тексту карточки. Счётчик у кнопки «Все» считается автоматически.

## Дизайн

Стиль взят из `styles.css` сайта 3d-group.space:
- размеры в `rem`; на десктопе `1rem = 10px` при ширине 1920, дальше масштабируется вместе с экраном;
- шрифты: SuisseIntl для заголовков (капс, трекинг −0.0275em) и Montserrat для текста;
- цвета: `#101010` текст, `#202020` тёмные блоки, `#f1f1f1` фон карточек, фирменный градиент `#8247ED → #EB8F73` (миксин `brand-gradient`);
- шапка с `mix-blend-mode: difference`, стеклянные кубы с параллаксом, наведение на карточку с пунктирным кругом «Читать кейс» — как на главной.

**Шрифт SuisseIntl.** Файлы лежат на сайте в `/local/templates/leadspace/assets/fonts/`. Их нужно положить в `src/assets/fonts/` и подключить через `@font-face`. Пока вместо него стоит Inter.

## Карточка кейса и автозаполнение

Карточку можно выводить из инфоблока Битрикса без ручной подгонки:
- иконка кейса (PNG с прозрачным фоном) вписывается по центру серого блока;
- высота карточки подстраивается под текст, длинный текст обрезается (заголовок до 2 строк, строки таблицы до 2, на телефоне до 4);
- если у кейса нет какого-то поля, строку `case-card__row` просто не выводим;
- в списках «Решение» и «Проверено» точки-разделители рисует CSS, в данных — обычный `<ul><li>`.

| Что в карточке | Поле инфоблока (пример) | Тип |
|---|---|---|
| Ссылка | `DETAIL_PAGE_URL` | — |
| Обложка (3D-рендер) | `PREVIEW_PICTURE` | картинка 16:9; класс `case-card__media--cover`, всегда цветная |
| Скриншот CRM (вместо обложки) | `PREVIEW_PICTURE` | картинка; класс `case-card__media--shot`, чёрно-белая, цветная при наведении |
| Иконка (если скриншота нет) | `ICON` | картинка PNG |
| Плашка «N сотрудников в CRM» | `WORKPLACES` | число |
| Заголовок | `SPHERE` | строка |
| Отрасль | `INDUSTRY` | строка |
| Решение | `SOLUTIONS` | множественная строка |
| Проверено | `RESULTS` | множественная строка |
| Задачи (плитки «Какие задачи мы уже решали») | `TASKS` | множественный список из 9 пунктов |
| Фильтры | `data-sphere`, `data-format`, `data-tags`, `data-tasks` | списки |

Кейсы на странице — 8 кейсов с главной сайта (сфера, рабочие места, иконка, ссылка). Строки «Решение» и «Проверено» заполнены только у «Банкротства физлиц» данными из макета. Сферы, задачи, формат и платформа проставлены примерно — их нужно сверить.
